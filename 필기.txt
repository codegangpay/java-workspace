git ->버전관리 시스템 -> 지정한 폴더의 변경사항을 감지해서 적용여부를 결정

1. commit
이전 commit시점부터 변경된 사항들을 새로운 버전으로 저장(로컬저장소)

2. 변경사항 취소
    2-1. discard change
    commit 되기 전의 변경사항을 취소

2-2. revert
    commit된 이후 변경사항을 취소 해당 버전의 변경사항을 되돌려서 새로운 버전을 생성
    협업시 사용 가능

2-3. reset
    commit된 이후 변경사항을 취소 해당 버전의 시점 상태로 되돌아감
    협업시 사용 불가능

3. push
로컬저장소의 버전을 원격저장소에 반영(로컬저장소가 버전이 더 높은상태에서 진행)
4. pull
원격저장소의 버전을 로컬저장소에 반영(원격저장소가 버전이 더 높은상태에서 진행)
